# Updated Prompt – Role-Based System (Super Admin / Admin Partner / User)











## User Roles



### 1. Super Admin



The Super Admin has complete control over the entire platform.



Permissions:



* View every parcel created across all partners/offices.

* View all users, admins, offices, and partners.

* Create, edit, delete, or suspend any account.

* Create and manage Admin Partner accounts.

* Assign or revoke permissions.

* Manage all parcels, invoices, bills, expenses, payments, reports, and settings.

* View complete analytics and dashboards.

* Transfer parcels between partners if needed.

* Change parcel status at any stage.

* View activity logs of every action.

* View who created, updated, delivered, cancelled, or modified every parcel.

* Manage system settings, pricing, parcel charges, notifications, and other global configurations.

* Only Super Admin can change system-wide settings and permissions.



---



### 2. Admin Partner



Admin accounts are created only by the Super Admin.



This role is designed for franchise offices or business partners.



Permissions:



* Login to their own dashboard.

* Create parcels.

* Edit their own parcels.

* Update parcel status.

* Generate invoices, bills, receipts, and reports for their own business.

* Manage customers created by their own office.

* View only their own parcels.

* View only their own customers.

* View only their own financial reports.

* View only their own expenses.

* View only their own earnings.

* View only their own staff (if enabled).



Restrictions:



* Cannot access other partners' parcels.

* Cannot access Super Admin dashboard.

* Cannot view global users.

* Cannot change system settings.

* Cannot change permissions.

* Cannot delete system records outside their own office.

* Cannot see data belonging to another partner.



Every parcel created by an Admin Partner must automatically store:



* Created By

* Partner Name

* Office Name

* Created Date

* Last Updated By

* Last Updated Time



---



### 3. User



Users have the most limited access.



Permissions:



* Login securely.

* Create their own parcel requests (if enabled).

* Track only their own parcels.

* View only their own parcel history.

* View invoices related to their own parcels.

* Update personal profile.



Restrictions:



* Cannot access admin dashboards.

* Cannot access other users' data.

* Cannot modify system settings.

* Cannot view reports.

* Cannot manage parcels belonging to others.

# Security Rules



* Implement proper Role-Based Access Control (RBAC).

* Protect all pages using secure route guards.

* Enforce Row-Level Security (RLS) in Supabase.

* Prevent unauthorized data access.

* Every query must return only the data allowed for that user's role.

* Log every important action for auditing.
